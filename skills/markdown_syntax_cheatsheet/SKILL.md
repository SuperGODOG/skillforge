## Overview
面向正在编写 Markdown 文档、需要快速确认语法写法的用户。提供表格、代码块、链接、图片、标题、列表、引用、强调等常用语法的最简速查，以主流 Markdown 通用语法为主。不讲解渲染器私有扩展。

## Instructions
1. 先判断用户需要哪个语法类别：表格 / 代码块 / 链接 / 图片 / 标题 / 列表 / 引用 / 强调。
2. 回答结构固定为：语法模板 -> 最小示例 -> 关键注意点。
3. 各类别速查要点：
   - 表格：用管道符 `|` 分隔单元格，表头下方必须有分隔行。分隔行中 `:---` 表示左对齐，`:---:` 表示居中，`---:` 表示右对齐。
   - 代码块：用三个反引号作为围栏，写在独立一行；起始围栏后可直接写语言名。行内代码使用单个反引号。
   - 链接：内联式写法为 `[文字](https://example.com '可选标题')`；引用式写法为 `[文字][id]`，并在文档任意处定义 `[id]: https://example.com`。
4. 如果用户给出一段 Markdown 并询问含义，先拆分出涉及的语法点，再按上述速查要点回答。

## Examples
**Q**：Markdown 表格怎么让一列居中？
**A**：在表头下方分隔行的对应位置写 `:---:`。

```
| 左 | 中 | 右 |
| :--- | :---: | ---: |
| 1 | 2 | 3 |
```

**Q**：怎么插入 Python 代码块？
**A**：用三个反引号围栏并在开头写 python。

```python
print('hello')
```

**Q**：链接的标题是什么？
**A**：链接标题是可选的悬停提示文字，可放在链接地址后的单引号内。
